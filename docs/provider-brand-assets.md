The artwork is visually unmodified. In-app task and integration rows use the
full Codex app icon, the Claude Code crab, and Cursor app mark. Tiny menu-bar
flags use the adaptive Codex outline, the orange Claude Code crab, and the
light/dark Cursor mark. Normal flags have no backing disc; attention alone gets
an orange or red emphasis ring.
